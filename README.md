# Todo App
A responsive and error free web application made with HTML, tailwind CSS and majorly JS.

## JavaScript concept  used
- DOM manipulation.
- Event handling.  
- Function for each functionality.
- managing every task using Array/Object.
- local storage for data to persist.

## features
- Add new tasks, each being unique.
- editing a existing task.
- marking a existing task complete.
- deleting a task.
